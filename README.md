# VARSEP Investment Plotter

Static investment calculator and comparison tool with:

- daily CAGR compounding
- bounded input validation for calculator and comparison scenarios
- Chart.js visualizations with pinned CDN assets and SRI
- GitHub Pages-friendly static hosting

## Files

- `index.html` - app shell
- `style.css` - Carbon-inspired UI layer
- `app.js` - calculator logic and UI behavior
- `app.test.js` - production-backed Node test suite

## Local use

Open `index.html` in a browser, or serve the folder with any static file server.

## Test

```bash
node app.test.js
```

## GitHub Pages

This repo is ready for GitHub Pages. Publish the `main` branch root and the site will be served as a static app.
